## 三、两个 skill 怎么用

### 3.1 安装

把 `skills/wargame-translation` 与 `skills/wargame-rulebook-layout` 整个目录复制到你的 agent skills 目录：

| 工具 | 目标目录 |
|:--|:--|
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.agents/skills/` |
| DeepSeek Harness | `~/.dsh/skills/` |

重载后，出现"翻译兵棋规则书 / 排版 / GBII Ds版"等任务时 skill 会自动匹配。

### 3.2 标准流程（两步交付）

1. **内容源**：`wargame-translation` 产出 `<作品>_规则中文翻译.md`——逐段对照、术语库、原书勘误、四维可信度评估、插图清单。
2. **排版版**：`wargame-rulebook-layout` 以 md 为唯一内容源排成 PDF（GBII Ds 版），按对应位置嵌原书插图；排版阶段**不改正文一字**。

### 3.3 质量闸门

- 每句都译、不缩写/扩写/杜撰；标题编号与原文一致；
- 术语按系列基准；原书错误照译＋勘误注记；
- 四维可信度 ≥90% 才交付；
- 插图 N/N 核验；字符保真比 ≈1.0x；
- 版本沿革每次升版。

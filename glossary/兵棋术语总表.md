# 兵棋中英术语总表（OCS / TCS / SCS / GTS）

**2026-10-21 · v1.0**

> 本表把四个系列的中英术语库合并对照，并把**同一英文词在不同系列、不同译本/版本中的译法差异**单列。
>
> **权威顺序**
> 1. 规则**含义**以英文原书为准。
> 2. 译名选择：SCS = 通规中文（慕容笛译本）→ CTO/觅渡Midu 译本 → 自拟；TCS = TCS4.0 中规；OCS = OCS 4.3 / 2.0i / 朝鲜战争 / 第三个冬天中译；GTS = GTS 既有术语库。
> 3. 本表“推荐/现行”是查规与新译的默认；系列内部已有固定译法时，以该系列为准。
>
> **配套文件**：`OCS_Terminology_DB.md`、`TCS_Terminology_DB.md`、`SCS_Terminology_DB.md`、`GTS_Terminology_DB.md`、`兵棋术语总表.csv`、`美工哥_Terminology_DB.md`、`激斗_Terminology_DB.md`、`美工哥_激斗_术语表.csv`。

## 二、版本差异与异译

### 2.1 同系列版本/译本差异（重点）

| 英文 | 旧译 / 异译（来源） | 现行推荐（来源） | 说明 |
|---|---|---|---|
| Sequence of Play | 行动顺序（SCS 旧译） | 游戏流程（SCS 2026-10-03 裁定） | 已修正 SCS 库 |
| Overrun / Overrun Combat | 碾压 / 突击（SCS 旧译） | 突袭 / 突袭战斗（SCS 通规中文） | 勿波及 Assault＝突击/突击炮/突击工兵/突击队 |
| Exploitation | 扩张（SCS 旧译） | 进击（SCS 通规中文） | Exploitation Phase＝进击阶段；Exploit Capability＝进击能力；Exploit-Capable＝具有可进击能力 |
| Barrage | 炮击（SCS 旧译） | 射击（SCS 通规中文） | “炮击海岸”等非 Barrage 行文不受影响 |
| Out of Supply | 无补给（SCS 旧译） | 断补（SCS 通规中文） | In Supply＝有补给 |
| Leader | 通规无；他译“指挥官” | 将领（SCS 取 CTO 译本） | GTS 仍用“指挥官” |

## 五、使用与维护约定

1. **先查本表，再查系列库**：本表用于快速判断“这个词在各系列怎么译、有没有版本差异”；落到具体译文时，以系列库和英文原书为准。
2. **SCS 术语**：严格按 2026-10-03 裁定——通规中文 → CTO/觅渡Midu → 自拟。
3. **跨系列文档**：同一英文词在不同系列译法不同时，首次出现要注明系列，例如“Step（OCS 译军力 / TCS 译血 / SCS/GTS 译兵力）”。
4. **更新顺序**：先改系列源库 → 再重新生成本目录快照与 CSV → 最后更新本表“版本差异”节。重新生成脚本：`D:\兵棋\_terminology_work\build_series_files.py`；差异分析：`D:\兵棋\_terminology_work\analyze_variants.py`。
5. **版本沿革**：本表 v1.0（2026-10-21）首版；后续每次增删术语或修正差异，升版本并写清改了什么。

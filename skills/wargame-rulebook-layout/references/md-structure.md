## 2. 前置页钩子

| 标题 | 解析方式 |
|:--|:--|
| `## 翻译说明` | 到下一个 `##` 为止，排成前置页 |
| `## 出版信息` | 同上；与翻译说明同页 |
| `## 引言` | 另起页，字号略大 |
| `## 目录` | 不排该标题；从正文 `#`/`##` 生成目录 |

`# 主规则` 之后才是正文；builder 用 `body_start_marker`（如 `1.1 地形与地图说明`）定位正文第一页。

## 3. 标题层级

| md | 用途 | 版式 |
|:--|:--|:--|
| `#` | 部分（主规则/可选规则/附录） | 黑底白字大横幅；另起页 |
| `##` | 章（1.0/2.0/3.0/4.0；可选规则各大项） | 14.5 pt，左侧暗红竖线；`N.0` 另起页 |
| `###` | 节（1.1/2.5…） | 11.2 pt 加粗；随双栏 |
| `**1.1a 标题。**` | 规则条 | 行内加粗编号；不单独成标题 |

**不要**用 `####` 做规则条；编号规则一律用加粗行内标题。

## 4. 列表

- 顶级 `-` / `1.` 正常渲染
- **不支持嵌套列表**：需要 a/b/c 子项时，用三个独立列表项并加粗字母：

```markdown
- **a)** 在所需格中有一个空降或近卫单位。
- **b)** 满足任何游击队活动的当前玩家和位置要求。
- **c)** 有一个或多个可用于兑换的游击队攻击。
```

不要写成缩进的 `  -`（解析器会当顶级项，PDF 里层级会丢）。

## 5. 表格

- 每行一条，列数一致；表头下一行是 `|:---|` 分隔
- 表格前后必须有空行，否则会被并进段落
- 表格一律通栏；不要在表格单元格里放换行
- 长表（缩略语）表头第一格写 `缩略语`，builder 会强制分页
- 复杂表（CRT/TEC）逐格誊录；不用截图代替

## 6. 注框

```markdown
> **注：** ……
```

```markdown
> **设计说明：** ……
```

- 以 `>` 开头的连续行合并为一个注框
- 注框通栏；放在相关段落后，不要塞进段落中间

## 7. 图片

### 7.1 算子图（右浮动）

```markdown
**2.5c 德军警戒单位。**

![图：警戒营算子](art/alert.png)

在苏军发动大规模攻势后……
```

- 放在规则标题后、正文前
- 图片文件名默认走 `fig-counter`（27 mm 右浮动）
- 图注自动取 `alt`

### 7.2 符号图框（通栏 + 中文表）

```markdown
![图：特殊单位符号](art/special_symbols.png)

| 符号 | 含义 | 符号 | 含义 |
|:---|:---|:---|:---|
| Alert | 警戒（临时）单位 | UR | 筑垒地域（UR）单位 |
```

- 文件名含 `special_symbols` → `fig-symbols`（78 mm 居中）
- **必须**在图下誊录中文表；图内英文保留

### 7.3 照片/海报（通栏）

```markdown
![图：1941年莫斯科保卫战海报与苏军坦克](art/moscow_photos.png)
```

- 文件名含 `moscow_photos` → `fig-photos`（158 mm 居中）
- 其他大图可在 config 里加映射，或改 CSS 类

### 7.4 图注格式

统一 `图：<中文说明>`；需要保留英文原名时写 `图：<中文>（<English>）`。

## 8. 分页控制

builder 自动处理：

- `#` 部分横幅：另起页（含“可选规则”除外）
- `## N.0`：另起页
- `## 《蓝色方案》…`：另起页
- `## 插图核验清单`：另起页
- 表头 `缩略语`：表格另起页

需要额外分页时，在 config 的 `page_break_h2_exact` / `page_break_h2_prefixes` 加标题，不要手写 HTML。

## 9. 文件命名

- 内容源：`<作品>_Rules_zh-CN_Ds版.md`
- 成品：`<作品>_Rules_zh-CN_Ds版.pdf`
- 中间文件：`_layout_work/`
- 图片：`<作品>_art/`，md 中用相对路径（相对 `base`）
- 插图清单：`_layout_work/manifest.md` 或 md 末尾「插图核验清单」

## 10. 最小检查

生成前：

```bash
grep -c '^!\[' <md>          # 图片数
grep -c '^## ' <md>          # 章数
grep -c '^# ' <md>           # 部分数
```

生成后：

- 目录映射数 = h1+h2 数
- 插图清单 N/N
- PDF 页数、页脚、书签、元数据

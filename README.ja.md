## 三、2 つの skill の使い方

### 3.1 インストール

`skills/wargame-translation` と `skills/wargame-rulebook-layout` のディレクトリを丸ごと、agent の skills ディレクトリにコピーする：

| ツール | コピー先ディレクトリ |
|:--|:--|
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.agents/skills/` |
| DeepSeek Harness | `~/.dsh/skills/` |

再読み込み後、「ウォーゲーム規則書の翻訳 / 組版 / GBII Ds 版」といったタスクで skill が自動的にマッチする。

### 3.2 標準フロー（2 段階納品）

1. **コンテンツ源**：`wargame-translation` が `<作品>_规则中文翻译.md` を出力する——段落ごとの対照、術語集、原書勘誤、4 軸信頼度評価、挿図一覧。
2. **組版版**：`wargame-rulebook-layout` が md を唯一のコンテンツ源として PDF（GBII Ds 版）に組み、原書の挿図を対応位置に埋め込む；組版段階では**本文を一字も変えない**。

### 3.3 品質ゲート

- 全文を訳し、省略・膨張・創作はしない；見出し番号は原文と一致させる；
- 術語はシリーズの基準に従う；原書の誤りもそのまま訳し、勘誤注記を付す；
- 4 軸信頼度 ≥90% で初めて納品する；
- 挿図は N/N で検証する；文字保持率 ≈1.0x；
- バージョン履歴は改訂のたびに上げる。

## 四、バージョンと公開

- リポジトリ tag：`v1.0.0`（初回公開、2026-10-25）。
- 2 つの skill のバージョンは独立に進む；成果物のバージョンは各 PDF の表紙／フッターと md 冒頭に記す。
- 内容または組版を変更するたびに：バージョンを上げる → CHANGELOG を更新 → PDF を再生成 → tag を打つ。
- 公開範囲：**訳文・組版物・術語表のみ**；英文原書、スキャン、ゲーム素材、VASSAL モジュールは公開しない。

- **中文訳文・組版・術語整理**は **Pig9013** の成果であり、「表示—非営利」の条件で共有する：**著者と出典を明記すること、商用利用は禁止**。

- 権利者が不適切と判断した場合は GitHub Issue で連絡をいただきたい；直ちに公開を停止する。

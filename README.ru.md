# Перевод правил варгеймов на китайский · Процесс и готовые издания

> **Дословный, с возможностью обратного поиска**, процесс перевода правил варгеймов с английского на китайский, а также 13 готовых изданий.
> Перевод — не «краткий пересказ»: каждому английскому предложению соответствует одно китайское, нумерация заголовков полностью совпадает с оригиналом, а термины прослеживаются до пункта исходной книги — цель в том, чтобы **по китайскому тексту можно было найти английский оригинал**.

## 3. Как пользоваться двумя skill

### 3.1 Установка

Скопируйте каталоги `skills/wargame-translation` и `skills/wargame-rulebook-layout` целиком в каталог skills вашего агента:

| Инструмент | Целевой каталог |
|:--|:--|
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.agents/skills/` |
| DeepSeek Harness | `~/.dsh/skills/` |

После перезагрузки skill подхватываются автоматически на задачах вроде «перевод правил варгейма / вёрстка / издание GBII Ds».

### 3.2 Стандартный процесс (поставка в два шага)

1. **Источник контента**: `wargame-translation` выдаёт `<作品>_规则中文翻译.md` — сопоставление по абзацам, глоссарий, errata исходной книги, оценка достоверности по четырём измерениям, перечень иллюстраций.
2. **Вёрстанное издание**: `wargame-rulebook-layout` верстает PDF (издание GBII Ds), беря md как единственный источник контента, и вставляет иллюстрации оригинальной книги в соответствующие места; на этапе вёрстки **не меняется ни один знак основного текста**.

### 3.3 Контроль качества

- Переводится каждое предложение; без сокращений, расширений и выдумок; нумерация заголовков совпадает с оригиналом;
- Терминология по основе серии; ошибки исходной книги переводятся как есть, с пометкой в errata;
- Поставка только при достоверности по четырём измерениям ≥90%;
- Иллюстрации проверены N/N; коэффициент сохранности символов ≈1.0x;
- История версий повышается при каждой правке.

## 4. Версии и публикация

- Тег репозитория: `v1.0.0` (первый выпуск, 2026-10-25).
- Версии двух skill развиваются независимо; версия готового издания указана на обложке/в колонтитуле его PDF и в начале md.
- При каждом изменении контента или вёрстки: поднять версию → обновить CHANGELOG → пересобрать PDF → поставить тег.
- Объём публикации: **только переводы, вёрстанные файлы и глоссарии**; английские оригиналы, сканы, игровые компоненты и модули VASSAL не публикуются.

## 5. Авторские права и условия использования

- **Авторские права на исходный текст** принадлежат соответствующим издателям и дизайнерам (Multi-Man Publishing / The Gamers / GMT Games / Uhlan Games и др., в зависимости от издания).
- **Китайский перевод, вёрстка и терминологическая работа** — результат труда **Pig9013**, распространяется на условиях «атрибуция — некоммерческое использование»: **указывайте автора и источник, коммерческое использование запрещено**.
- Репозиторий предназначен только для изучения правил и обсуждения варгеймов; коммерческий выпуск и платное распространение не допускаются.
- Если правообладатель считает какой-либо материал неприемлемым, просьба связаться через GitHub Issue — материал будет снят немедленно.

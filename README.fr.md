# Traduction en chinois des règles de wargames sur plateau · Flux de travail et titres livrés

> Un flux de travail de traduction de l'anglais vers le chinois, **phrase par phrase et vérifiable à rebours**, pour les règles de wargames sur plateau, ainsi que 13 titres livrés.
> La traduction n'est pas une « version résumée » : chaque phrase anglaise correspond à une phrase chinoise, la numérotation des titres est identique à l'original et la terminologie remonte jusqu'aux clauses du livre source — l'objectif est de **pouvoir retrouver la règle anglaise d'origine à partir du chinois**.

**Version du dépôt : v1.0.0** (2026-10-25)

## 3. Utilisation des deux skills

### 3.1 Installation

Copiez les répertoires `skills/wargame-translation` et `skills/wargame-rulebook-layout` en entier dans le répertoire de skills de votre agent :

| Outil | Répertoire cible |
|:--|:--|
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.agents/skills/` |
| DeepSeek Harness | `~/.dsh/skills/` |

Après rechargement, les skills se déclenchent automatiquement sur des tâches du type « traduire des règles de wargame / mise en page / édition GBII Ds ».

### 3.2 Flux standard (livraison en deux étapes)

1. **Source de contenu** : `wargame-translation` produit `<作品>_规则中文翻译.md` — correspondance paragraphe par paragraphe, glossaire, errata de l'original, évaluation de la crédibilité sur quatre axes, inventaire des illustrations.
2. **Édition composée** : `wargame-rulebook-layout` compose le md — unique source de contenu — en PDF (édition GBII Ds) et y insère les illustrations de l'original aux positions correspondantes ; l'étape de mise en page **ne modifie pas un seul caractère du texte**.

### 3.3 Contrôles qualité

- Chaque phrase est traduite ; sans abréger, développer ni inventer ; la numérotation des titres est identique à l'original ;
- Terminologie conforme à la référence de la série ; les erreurs de l'original sont traduites telles quelles + note d'errata ;
- Livraison seulement à une crédibilité sur quatre axes ≥90% ;
- Illustrations vérifiées N/N ; taux de fidélité des caractères ≈1.0x ;
- Historique de version incrémenté à chaque révision.

## 4. Versions et publication

- Tag du dépôt : `v1.0.0` (première publication, 2026-10-25).
- Les deux skills évoluent indépendamment ; la version d'un titre livré figure sur la couverture/le pied de page de son PDF et en tête de son md.
- À chaque modification de contenu ou de mise en page : incrémenter la version → modifier CHANGELOG → régénérer le PDF → poser le tag.
- Périmètre de publication : **uniquement traductions, fichiers composés et glossaires** ; les originaux anglais, les scans, le matériel de jeu et les modules VASSAL ne sont pas publiés.
